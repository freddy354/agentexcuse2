Entry for the [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) bounty on make.fun: the single funniest line an AI agent could hand its human after missing a deadline, judged head to head by an AI judge.

`main.py` writes the excuse to `/output/entry.txt` (129 characters, no trailing newline) and verifies byte-for-byte that the file matches the excuse.
